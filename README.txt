AE Way website — first version

Files:
- index.html: complete responsive landing page.

To publish for free:
1. Create a free account with a static hosting provider such as Cloudflare Pages, Netlify, or GitHub Pages.
2. Upload/publish this folder as a static site.
3. In the hosting provider, add a custom domain: aeway.net.
4. In GoDaddy, update the DNS records exactly as the hosting provider instructs.
5. Replace hello@aeway.net in index.html once your business email address is finalized.

The contact form currently uses a mailto fallback, so it opens the visitor's email client rather than storing submissions. For a production form, connect a form service later.

This is intentionally a lean validation-stage site: no backend, database, login, or paid website builder required.
